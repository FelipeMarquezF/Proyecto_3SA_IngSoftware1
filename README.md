# Sistema de Gestión de Ventas e Inventario - Panadería Trigo Dorado

## Descripción
Sistema web para digitalizar el registro de ventas, el control de inventario
y la gestión de productos de la panadería "Trigo Dorado" (Quito, Ecuador),
reemplazando el registro manual en cuadernos físicos.

## Objetivo
Desarrollar una aplicación web que automatice el registro de ventas, controle
el inventario y mejore la gestión de la información para optimizar las
operaciones diarias del negocio.

## Funcionalidades principales
- Registro y gestión de productos (CRUD)
- Registro ágil de ventas con cálculo automático de subtotal, IVA y total
- Control automático de inventario con alerta de stock mínimo
- Generación de reportes de ventas (diarios, semanales y mensuales)

## Herramientas utilizadas
- draw.io (diagramas UML)
- Microsoft Project (cronograma)
- Visual Studio Code (Python)
- Git y GitHub (control de versiones)

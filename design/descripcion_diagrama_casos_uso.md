# Diagrama de casos de uso

El diagrama (diagrama_casos_uso_final.drawio) representa 7 casos de uso
principales del sistema: gestionar productos, registrar venta (con
actualizacion automatica de inventario), gestionar proveedores, generar
reportes y administrar usuarios.

El actor Vendedor puede registrar ventas, consultar productos y gestionar
proveedores. El actor Administrador tiene acceso adicional a los reportes
de ventas y a la administracion de usuarios del sistema.

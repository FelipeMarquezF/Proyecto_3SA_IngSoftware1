# Código fuente del sistema

Esta carpeta contiene el **prototipo interactivo del sistema**
(`trigo_dorado_sistema.html`), desarrollado en HTML/CSS/JavaScript, que simula
el funcionamiento de los módulos de:

- Inicio de sesión y control de acceso por roles
- Gestión de productos
- Registro de ventas (con cálculo automático de subtotal, IVA y total)
- Consulta de inventario y alertas de stock mínimo
- Gestión de proveedores
- Reportes de ventas
- Administración de usuarios

El prototipo funciona con datos de ejemplo en memoria, sin conexión a un
servidor ni a una base de datos real. Su propósito es validar la usabilidad y
los flujos de trabajo del sistema antes del desarrollo final (OE4).

## Cómo probarlo
Abrir el archivo `trigo_dorado_sistema.html` directamente en un navegador web
(no requiere instalación ni conexión a internet).
